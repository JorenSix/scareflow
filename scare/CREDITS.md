# Scare sound credits

These sounds were processed so the attack starts immediately: peak normalised to -1 dBFS, everything before the onset removed (30 dB below peak), a 3 ms anti-click fade-in, trailing silence trimmed, and long sounds capped at 10 s with a fade-out. Sounds that built up slowly were then cut to start 5 ms before they reach -6 dB of their peak, with a 2 ms fade-in, so every scare hits within about 5 ms. All files are 44.1 kHz 16-bit stereo WAV.

The audio files are not in git (see `../.gitignore`); download them from the sources below. All sources are on Wikimedia Commons; the file pages are at `https://commons.wikimedia.org/wiki/File:<source name>`.
